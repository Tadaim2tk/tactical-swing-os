# CI artifact 救出アーカイブ（as-seen 一次データの恒久保存）

CI artifact の保持期間は90日で、2026-09-04 から最古分の失効が始まる状態だった
（docs/audit_blindspots_2026-08-31.md P1-7）。ここには **2026-07-15 以前に作成された
全 artifact 462件**を、失効前の 2026-08-31 に GitHub API 経由で救出し、zip のまま収めた。

- 各 zip は当時の run が保存したそのままの内容（`data/raw/*.csv` = **その朝モデルが見ていた
  as-seen の価格系列**、`results/*` = 当時の生成物、news 系はヘッドラインCSV/JSON）。
- 再取得した現在の価格履歴とは、取得時点で進行中だったバーの値が異なる（実測で最大±1.2%、
  同監査 P2-d）。遡及検証で「当時の値」が必要なときは必ずこちらを使うこと。
- `manifest.tsv`: artifact id / created 日 / 名前 / バイト数。
- ファイル名: `<created日>_<artifact名>.zip`。
- 2026-07-16 以降の artifact（失効は10月以降）の恒久化方針は 9/1 月次で決定する。

人間判断（2026-08-31）: 公開リポジトリへの収載を了承のうえ恒久化。
