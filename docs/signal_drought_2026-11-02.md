# シグナルが出なくなった問題の診断（2026-11-02）

人間の指摘「最近シグナルが出なさすぎる」「この売買頻度では、期待値に収束する前に市場のルールが変わる」
を受けた診断。結論を先に書く。

## 結論

1. **崖は 2026-09-11〜16 に起きた。相場のせいではない。** 9月は8月より5日先の値幅（ATR比）が大きく、
   10月は8月と同程度だった。8月は1日2.5行の注文を出していた相場で、10月は0.16行になった。
2. **原因はGPTの判断の仕方の変化で、きっかけはプロンプトの積み増しである。** 9/1〜9/9 の4回の変更
   （SL幅を戻す・rr検算・expected_r_basis・invalidation_check の毎日聞き直し・成行参加の注記）の直後に
   注文が 14日で 31行→8行 に落ち、GPTは「正式なB級」と「監視水準」という区別を作って B 行を
   書かなくなった。10月は31日中16日で、本文に監視資産を挙げながら台帳では全資産 NO_TRADE だった。
3. **試行回数は8月の時点で既に少なかった。** 8月の78行の注文は、同じ見立てを毎日書き直した8本の見立て
   だった（1本あたり平均11日）。独立した見立ては 6月18本 → 7月14本 → 8月8本 → 9月10本 → 10月5本。
   週2本に届いた月は6月だけ。
4. **誰も頻度を数えていなかった。** 気づくまで7週間かかった。今回、売買頻度を毎晩数えて床を割ったら
   日次ジョブを赤にする `tools/throughput_watch.py` を入れた。この規則で遡ると 9/16 に WARN、
   9/29 に ALERT が出ていた（実際に気づいたのは 11/2）。

## GPTの本文に見える仕組み（引用は data/prediction_log_archive/ から）

1. **同じ見立てを翌日に書き直さなくなった（9/11〜）。** invalidation_check で各 signal_id を5営業日
   追いかける形にした結果、GPTは判断を「1本の持続する対象」として扱い、翌日に帯を更新した B 行を
   出さなくなった。9/14「9/12 SELLのEntry 79200–79800からさらに離れており、**ここからSELLするのは
   追随です**」。10/20「現時点で改めてSELLする場合は、**全く別のEntry、SL、TPを設定し、別のsignal_idを
   発行する必要があります**」——そして発行しない。
2. **「正式なB級」という語を作り、監視水準は台帳に書かなくなった。** 本文5・6節の「正式」の出現は
   8月1回・9月1回・**10月37回**。10/10「新規正式B級：なし。…押し目Entry帯、SL、TP、RR、MAE想定を
   まだ固定できないため、**正式なB級シグナルにはしません**」。10/27「新規B級：0件。…ただし、次の
   監視水準を設定します。[GOLD/NASDAQ/WTI/BTC の表] **これらは正式なシグナルではありません**」。
   プロンプトは「B級も監視用Entry帯とSLを定義する」としか言っておらず、8月はこの監視水準が
   そのまま B 行だった。
3. **A級の7条件を、その日の判断全体に当てている。** 10/20 の5節は A級必須条件の表
   （CBS≥75 / EMS≥65 / expected_r≥0.45 / MAE≤0.25R / RR≥1.2 / SL距離≤TP1の2倍 / XM最小ロット実損≤3,000円）
   を並べて「**実取引NO_TRADEです**」で終わる。8/15採用ルールの「満たさない場合はシグナル成立でも
   『実取引NO_TRADE』と本文に明記する」は本文の注記のつもりだったが、GPTは rank 自体を NO_TRADE にした。
   「実取引NO_TRADE」が本文に出る日の割合は 8月 0.19 → 10月 0.48。
4. **3,000円の実損上限が、最小ロットでは GOLD と NASDAQ の SL を 0.2〜0.3 ATR に押し込む。**
   10/20「3000/(250×158.54)≈0.0757 … XMの該当CFD銘柄で、その数量が最小ロットとして利用できることは
   **未確認です**」→ NO_TRADE。下の表のとおり、1ATR の SL を最小ロットで持つと GOLD は約16,000円、
   NASDAQ は約10,000円の実損になる。上限3,000円を守る SL は GOLD で 0.18 ATR、NASDAQ で 0.29 ATR。
   9/16 以降の実際の SL 幅は GOLD 0.45 ATR・NASDAQ 0.40 ATR・SPX 0.46・BTC 0.62・USDJPY 0.64・WTI 0.34
   （それ以前は 1.1〜1.9 ATR）。SL が当たりやすくなった（docs/sl_width_2026-10-23.md）のはこれで、
   当たった SL を GPT は次の見送り理由にする：10/27「BTCでは以前のBUY判断が短期間で失敗しました。
   …**再度BUYすることは避けます**」。
5. **追随禁止が、強いトレンドの日に全資産を止める。** 9/16 5節「方向確信だけなら、WTI BUY / US10Y上昇 /
   NASDAQ SELL / GOLD SELL の4つはかなり強いです。…**すべてEntry品質でA級失格です**」、7節「今日は、
   **方向を当ててもエントリーの期待値が悪い日**です」。9/9 に人間が承認した成行参加の規則（changelog(16)）
   は執行シミュレーションの側にあり、GPT が B 行を出さなければ何も追えない（9/9以降の chase 対象は7件）。
6. **イベント待ち。** 1節で FOMC/CPI/日銀を見送り理由に挙げた日の割合は 8月 0.13 → 10月 0.42。
   8月はイベント週でも B 行を出していた。

## 試行回数の話（人間の指摘の数式）

1回の結果 R の散らばりは約1R。平均 +0.2R/回 を 0 と区別するには（2σで）およそ
(2×1/0.2)² = 100 回いる。週1.1本なら 91週。6月の週8本なら 12週。
**頻度は期待値と同じ重さの指標**で、落ちたら期待値がどれだけ良くても意味がない。
だから頻度を毎晩数え、床を割ったら赤にする。床は「14日で見立て3本未満（週1本以下）」。

## 直すための提案（人間が ChatGPT タスク本文へ貼る。番号1〜4は記帳の明確化、5〜6は判断方針の変更）

貼る場所: 「## 運用ルール」の末尾。正本ミラー `prompts/tso_daily_signal_log.md` には同文を入れた。

```
- B級の記帳と「実取引NO_TRADE」の扱い（2026-11-03 明確化。changelog(19)）:
  1. B級監視候補に挙げた資産は、rank=B の行として記帳する。監視用のEntry帯・SL・TP1は暫定値でよい。
     「正式なB級」と「監視水準」を分けない。本文に監視水準を書いたのに TSO_LOG では NO_TRADE、
     という形は禁止（2026-10 はこの形が31日中16日あり、台帳が空の間は検証も執行シミュレーションも止まる）。
  2. A級条件（CBS≥75・EMS≥65・expected_r≥0.45・MAE≤0.25R・RR≥1.2・SL距離≤TP1距離の2倍・
     最小ロット実損≤3,000円）はA級の条件であって、B級の記帳条件ではない。B級は「方向の見立てがあり、
     監視用の帯とSLを書けること」で成立する。
  3. 「実取引NO_TRADE」は本文の注記であり、TSO_LOGの rank を変えない。最小ロットの実損が計算できない
     ときは本文に「未確認」と書き、rank は変えない。
  4. 見立てが続く日は、その日の帯とSLで毎日B行を出す（台帳は毎日の判断の記録であり、1本の見立てを
     1回だけ書く場所ではない。8月はこの形だった）。前日までの signal_id の invalidation_check は別に続ける。
  5. FOMC・CPI・日銀などのイベント前でもB行は出す。イベントは invalidation と本文に書く。
     イベント前に見送ってよいのは A級の新規だけ。
  6. 直前の判断が SL や fired になったことは、同じ資産の新しい見立てを止める理由にしない。
     止めるなら価格構造の理由を本文に書く。
```

人間が決めること（お金の話なので提案だけ）:

- **3,000円上限の扱い。** (a) 上限を据え置き、GOLD/NASDAQ は研究用の B 行だけ出して実取引は
  WTI/USDJPY/BTC に絞る（本文の注記で区別、rank は変えない）。(b) 上限を 1ATR の SL が入る額
  （GOLD で約16,000円、NASDAQ で約10,000円）まで上げる。(c) 口座種別（マイクロ）で最小ロットを
  下げられるか確認する。どれでも、**SL の幅を 3,000円に合わせて縮める運用はやめる**
  （縮めた SL が当たり、当たった SL が次の見送りを生んでいる）。
- 追随禁止の文「供給ショック直後のmomentum追随、entry帯未到達での成行追い…を避ける」は、
  9/9 に承認した NASDAQ/BTC/USDJPY の成行参加規則と矛盾している。「避けるのはWTIの供給ショック直後の
  追随と参照系列の取り違え。3資産の成行参加は規則であり追随ではない」に書き換えるか、判断を仰ぐ。
