# 仮説登録簿（2026-09-03 開設）

「効かなかった」を一つの箱に入れない。検定した仮説は必ず**4つの型のどれか**に分類する。

| 型 | 意味 | 次の一手 |
|---|---|---|
| **生存** | 予想どおりの符号で有意 | 運用へ載せる候補。ただし多重比較の補正後で判断 |
| **ゼロ** | 十分な検出力があるのに効果が見当たらない | その方向を捨てる。逆張りも取れない |
| **逆が真** | 符号が逆で有意 | **裏を本命として立て直す**。単なる棄却ではない |
| **検出力不足** | 件数が足りず判定できていない | 件数を増やすか、問いを別の母集団へ翻訳する |

検定の共通規約: as-of（判定はD-1までの情報、結果はD以降）／連続日は資産×バーストで
クラスタ化して入れ替え／月ブロック単位の並べ替え／試した切り口の数を必ず記録。

## この登録簿の使い方

1. 新しい仮説を検定したら、**必ずこの表のどれかに書く**。結果を書かずに次へ進まない。
2. 「ゼロ」に入れた仮説は再検定しない（多重比較を自分で増やさないため）。
   再検定するなら、母集団か目標統計量を変える理由を先に書く。
3. 「検出力不足」は**時間で解決するもの**と**設計で解決するもの**を分ける。
   前者は待つ。後者は問いを別の母集団へ翻訳する（主役レンズは台帳→5年コーパスへ翻訳して答えが出た）。
4. 「逆が真」が出たら、それは失敗ではなく**新しい本命**である。裏を仮説として登録し直す。
