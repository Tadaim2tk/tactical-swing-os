# 仮説登録簿（2026-09-03 開設）

「効かなかった」を一つの箱に入れない。検定した仮説は必ず**4つの型のどれか**に分類する。

| 型 | 意味 | 次の一手 |
|---|---|---|
| **生存** | 予想どおりの符号で有意 | 運用へ載せる候補。ただし多重比較の補正後で判断 |
| **ゼロ** | 十分な検出力があるのに効果が見当たらない | その方向を捨てる。逆張りも取れない |
| **逆が真** | 符号が逆で有意 | **裏を本命として立て直す**。単なる棄却ではない |
| **検出力不足** | 件数が足りず判定できていない | 件数を増やすか、問いを別の母集団へ翻訳する |

検定の共通規約: as-of（判定はD-1までの情報、結果はD以降）／連続日は資産×バーストで
クラスタ化して入れ替え／月ブロック単位の並べ替え／試した切り口の数を必ず記録。

## 逆が真（符号が逆で、裏が新しい仮説になる）

| 仮説 | 何が逆だったか | 扱い |
|---|---|---|
| **通貨型（金↑銀↑銅↓）の局面は、その後の金の伸びが大きい** | 予想は「安全資産買いが続く」だったが、実測は **−1.083%(p=0.012)** で、通貨型の後の金は産業型の後より**弱い** | **裏を本命として登録**: 「金が銀と一緒に上がり銅が置いていかれた局面は、金の上昇の終盤である」。銀・銅の切り分けは向きが逆だが**情報を持っている** |

**この1件の意味**: 銀・銅をERSから借りた甲斐があった。当初4仮説とも「ゼロ」に見えたのは
検定手法の誤り（月ブロックの潰し込み・1日分の先読み・将来を含む閾値）のせいで、
直したら1件が有意な逆符号として現れた。**「効かない」と「逆が真」は手法の精度で入れ替わる**。

裏仮説の検証計画: 金のロング判断を「通貨型局面かどうか」で層別し、通貨型のときは
利確を早める／新規を見送る、が成立するかを次回の月次で見る（現時点では観察のみ・運用不変）。

**候補（未確定）**: B+観察枠は行単位で「印がある方が成績が悪い」（55% vs 77%）と出たが、
トレード単位に束ねると差は+0.046・p=0.80で消え、**逆でもない**。
「逆が真」と誤認しかけた実例として記録する（research_bplus_2026-09-01）。

**crypto の見送り率について**: BTC 72%・ETH 83%が見送り（全資産で最も高い）。
これは日次プロンプトの「ETF/CME根拠不足ならNO_TRADE優先」が効いている可能性が高いが、

記録を開始（changelog(14)）。見送りが「棄権」なのか「判断の結果」なのかを分けてから測る。

## この登録簿の使い方

1. 新しい仮説を検定したら、**必ずこの表のどれかに書く**。結果を書かずに次へ進まない。
2. 「ゼロ」に入れた仮説は再検定しない（多重比較を自分で増やさないため）。
   再検定するなら、母集団か目標統計量を変える理由を先に書く。
3. 「検出力不足」は**時間で解決するもの**と**設計で解決するもの**を分ける。
   前者は待つ。後者は問いを別の母集団へ翻訳する（主役レンズは台帳→5年コーパスへ翻訳して答えが出た）。
4. 「逆が真」が出たら、それは失敗ではなく**新しい本命**である。裏を仮説として登録し直す。
