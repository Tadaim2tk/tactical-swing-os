## 0. 言葉

| 言葉 | 中身 |
|---|---|
| 注文 | 台帳の rank A/B で向きのある行。1資産1日1行 |
| 見立て | 同じ資産・同じ向きの注文が3日以内に続く並び（`src/throughput_metrics.py`） |
| 決着 | 執行シミュレーションの status が SL・TP1・時間決済のどれか。R は `r_result` |
| 建玉・含みR | 約定済みで未決着の行と、それを最新の日足の終値で測った R（`src/open_book.py`）。**確定ではない** |
| 確定＋含み | その日までに決着した R の合計 ＋ その日の建玉の含みR。週は月曜〜日曜 |
