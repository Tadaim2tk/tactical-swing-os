# 仕様凍結: Deflated Sharpe Ratio (多重検定補正)

- status: **active (frozen)**
- spec_id: SPEC-DSR-001
- frozen_at: 2026-06-15 (JST)
- 実装: `src/stat_guards.py`
- 適用箇所: `build_monthly_calibration.py`
- 前提仕様: SPEC-SG-001 (統計ガード)

## 1. 目的

3大課題③「過学習への自動ブレーキ」の強化。SPEC-SG-001 の単独t検定は、
**多重検定(選択バイアス)** を補正していなかった。

月次較正は asset / rank / side / regime / narrative_alignment にわたり
多数のセル(最大で数十〜数百)を**同時に**検定する。純粋な偶然でも
一部のセルは p<0.05 を満たすため、そのセルに重み変更を提案すると
「偶然の好成績への過剰適合」が起きる。これは憲章「後知恵バイアスこそ最大の敵」
の統計版である。

Deflated Sharpe Ratio (Bailey & López de Prado, 2014) は、
「N回の試行で期待される最大Sharpe」を帰無仮説の基準に据え、
観測Sharpeをその基準で割り引く。偶然の最大値を超える確率が
高いセルのみを「本物の優位性」と認める。

## 2. 凍結された閾値

| 定数 | 値 | 意味 |
|---|---|---|
| `DEFLATED_SHARPE_CONFIDENCE` | 0.95 | 増加提案を認めるDSRの下限(多重検定後も95%の確信) |

## 3. 計算

1. **試行数 N**: `gather_trial_context()` が全較正セルを横断し、
   closed評価 >= `MIN_SAMPLES_WEIGHT_CHANGE`(30) のセル数を数える
   (= 検定対象になり得たセルの数)。
2. **セル間Sharpe分散 σ²**: 上記セルのSharpe比の標本分散。
3. **期待最大Sharpe** SR\*:
   `σ · ((1−γ)·Z⁻¹(1−1/N) + γ·Z⁻¹(1−1/(N·e)))`
   (γ = オイラー＝マスケローニ定数, Z⁻¹ = 標準正規の逆CDF)。
4. **確率的Sharpe比 (PSR)**: 歪度・尖度を補正し、真のSharpeが SR\* を
   超える確率を標準正規CDFで返す。
5. **DSR** = PSR(SR\*)。

## 4. ゲート規則 (SPEC-SG-001 への追加)

増加提案のゲート順:

1. n < 30 → 「データ不足」
2. p >= 0.05 → 「統計的有意性なし」
3. Sharpe <= 0.5 → 「増加提案を保留」
4. **DSR < 0.95 → 「Deflated Sharpe < 0.95 (多重検定で偶然の可能性) のため増加提案を保留」** ← 本仕様
5. 上記を全通過 → +0.03 / +0.05 を提案

- **減少提案には DSR ゲートを課さない**。SPEC-SG-001 と同じく、損失が
  統計的に確認された場合は Ruin 回避を優先し、攻撃方向にのみ非対称に
  過学習ブレーキを適用する。
- `n_trials = 1`(デフォルト)のときは多重検定補正なし = PSR(vs 0) に縮約し、
  従来挙動と一致する(後方互換)。
- reason文字列には DSR と N を必ず記録する: `DSR=0.973(N=42)`。

## 5. 技術的制約

- **scipy禁止**(SPEC-SG-001 と同じ)。標準正規CDFは `math.erfc`、
  逆CDF(probit)は Acklam の有理近似で実装(相対誤差 ~1.15e-9)。
- 数値検証は `test_stat_guards.py`(norm_cdf/ppf の往復、PSR、
  期待最大Sharpe、DSRによる偽陽性棄却)。

## 6. 設計判断の記録

- Sharpe は1トレードあたり(非年率)。観測R系列と同一単位で一貫させる。
- 試行数Nは「検定対象になり得たセル数」で数える(実際に提案が出たセルだけ
  数えると選択バイアスが二重にかかるため)。
- DSRは情報列としてではなく**ゲート**として機能させる(reason に必ず残す)。
