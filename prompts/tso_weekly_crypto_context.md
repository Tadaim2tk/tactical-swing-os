# TSO 週次 crypto 文脈タスク（ChatGPTタスク本文の正本）

status: 2026-09-03 新設。日次タスク "Crypto market update: macro vs regulation dynamics" を
**廃止し、週次へ畳んだ**もの（changelog(14)）。本ファイルはChatGPT側タスク本文の正本mirror
であり、両者を同時に改定する。

実行: **毎週土曜 11:30 JST**（週次レビュー workflow 12:10 の前。取込は次回のroute-3で人間経由）。
初回: 2026-09-05(土)、対象週の week_start は 2026-08-31。

---

## 目的

crypto を動かしているのが**マクロ（ドル・金利・株）なのか、crypto固有の要因（規制・ETF・
清算）なのか**を週1回だけ判定し、後から当否を測れる形で記録する。

規制の話は日単位では動かない。日次でこれを出すと、同じ内容が7回並ぶだけで
台帳にも残らず、読む側の注意だけを消費する（廃止の理由）。

## やらないこと（重要）

- **売買判断を書かない**。entry / SL / TP / rank / win_prob は日次タスク(07:00)の領分。
  ここに書くと同じ判断が2箇所に存在し、どちらが本物か分からなくなる。
- **日次タスクのBTC/ETH見送りを減らす目的で使わない**。根拠を揃えることが目的化すると、
  正直な棄権が作られた判断に化ける（B+印がスコアの内生化で無意味化した件と同型）。

## 出力（この2つだけ）

### 1. 記録行（閉じた語彙。この語以外を書かない）

```
CRYPTO_CTX,<week_start>,<driver>,<etf_flow_dir>,<cme_basis>,<regulation_event>,<confidence>
```

`week_start` は**まとめる週の月曜のYYYY-MM-DD**（土曜に実行するので5日前の月曜）。
月曜以外を書くと取込側で弾かれる。

| 欄 | 取りうる値 | 意味 |
|---|---|---|
| driver | `MACRO` / `IDIOSYNCRATIC` / `MIXED` / `UNKNOWN` | 今週のcryptoを動かした主因はどちらか（本タスクの主題） |
| etf_flow_dir | `INFLOW` / `OUTFLOW` / `FLAT` / `UNKNOWN` | 現物ETFの週間フローの向き |
| cme_basis | `CONTANGO` / `BACKWARDATION` / `FLAT` / `UNKNOWN` | CME先物ベーシスの状態 |
| regulation_event | `NONE` / `PROPOSAL` / `ENFORCEMENT` / `APPROVAL` / `HEARING` / `OTHER` | 今週あった規制イベントの型 |
| confidence | `HIGH` / `MEDIUM` / `LOW` | 上記4欄の確からしさ |

**UNKNOWN を選ぶことは失敗ではない**。取れなかったものを推測で埋める方が有害である。

### 2. 本文（400字以内）

- 上の分類の根拠を、**数字と固有名詞**で。「〜の可能性がある」で終わらせない。
- **先週の自分の分類の答え合わせを1文で**。先週 `driver` を何と書き、実際どうだったか。
  外れていたら外れたと書く（この1文だけが、このタスクが当たっているかを測る唯一の手段）。
- 使用モデル名を1行（測定器の版記録。日次タスクと同じ規約）。

## 検証設計（10月月次で見る）

- `driver=MACRO` と申告した週の BTC/ETH は、実際に DXY・US10Y との相関が高かったか。
  高くなければこのタスクの判定は当たっていない。
- 自己申告 confidence と当否の対応（HIGHが当たっているか）。
- 判定不能なら**判定不能と書く**。週次なので1年で52件、独立クラスタもほぼ52件になる
  （日次より件数は少ないが、疑似反復が無いぶん検定力はむしろ高い）。
